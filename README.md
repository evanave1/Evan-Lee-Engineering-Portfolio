# Evan H Lee — Engineering Portfolio

A biomedical engineering portfolio built with Next.js, Tailwind CSS, and Framer Motion. The visual system uses a dark navy / off-white / light electric-blue palette, source imagery from Evan H Lee's Digication portfolio, and source-backed About Me, project, education, work, JHU extracurricular, California activity, and special-thanks content.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm run start
```

## Project details
